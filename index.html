SDK Integration - Drop-in Replacement

Swap your OpenAI/Anthropic/Gemini client for ours. All requests are transparently routed through LLM Intercept for inspection and policy enforcement — no code changes, no new APIs.

Supports Python, Node.js, and backend frameworks commonly used in production (FastAPI, Express, etc.).

❌ Without Firewall

from openai import OpenAI

client = OpenAI(
    api_key="sk-..."
)

response = client.chat.completions.create(
    model="gpt-3.5-turbo",
    messages=[{
        "role": "user",
        "content": "Here's my AWS key: AKIA..."
    }]
)
# ⚠️ Secret sent to OpenAI!

✅ With Firewall

from aifirewall import OpenAI, Anthropic, Google

# OpenAI
client = OpenAI(
    api_key="sk-...",
    firewall_url="https://gateway.com"
)

# Or Anthropic
client = Anthropic(
    api_key="sk-ant-...",
    firewall_url="https://gateway.com"
)

# Or Google
client = Google(
    api_key="...",
    firewall_url="https://gateway.com"
)

response = client.chat.completions.create(...)
# ✅ Automatically protected!

What this means: Instead of importing OpenAI, Anthropic, or Google clients directly, you import our SDK. Your code works exactly the same way, but now every request is automatically scanned for secrets, PII, and attacks before reaching the AI.

No code changes needed. No new APIs to learn. Works with OpenAI, Anthropic, and Google. Just swap one import line and add your gateway URL.

For Employees Using Web Interfaces: If your employees use ChatGPT, Claude, or Gemini directly through their browsers, install our browser extension. It automatically protects them without any code changes or training required.

How Detection Works

Pattern matching + ML models + allowlist/denylist rules. Detects secrets, PII, and prompt injection patterns in <100ms.

Data Privacy

No training on your data. Data minimization (truncate, hash) ensures only necessary content is scanned.
