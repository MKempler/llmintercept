# Hosting Your Landing Page - Quick Guide

## 🚀 Fastest Options (Deploy Today)

### Option 1: Vercel (Recommended - FREE) ⭐

**Why:** Easiest, free, perfect for static sites

**Steps:**
1. Go to vercel.com
2. Sign up with GitHub
3. Click "New Project"
4. Import your repo OR drag & drop the `index.html` file
5. Deploy (takes 30 seconds)
6. Get URL: `yourname.vercel.app`

**Time:** 5 minutes
**Cost:** FREE
**Result:** Live website!

### Option 2: Netlify (Also FREE)

**Why:** Similar to Vercel, also very easy

**Steps:**
1. Go to netlify.com
2. Sign up
3. Drag & drop `index.html` folder
4. Get URL: `yourname.netlify.app`

**Time:** 5 minutes
**Cost:** FREE

### Option 3: GitHub Pages (FREE)

**Why:** If you're using GitHub anyway

**Steps:**
1. Create GitHub repo
2. Upload `index.html`
3. Go to Settings → Pages
4. Select main branch
5. Get URL: `yourname.github.io/aifirewall`

**Time:** 10 minutes
**Cost:** FREE

## 🎯 Recommended: Vercel (Easiest)

### Quick Setup:

1. **Create account** (2 min)
   - Go to vercel.com
   - Sign up with GitHub/Google

2. **Deploy** (3 min)
   - Click "Add New Project"
   - Drag & drop your `index.html` file
   - Or connect GitHub repo
   - Click "Deploy"

3. **Get URL** (instant)
   - You'll get: `aifirewall.vercel.app`
   - Or customize: `aifirewall.com` (if you have domain)

4. **Update links** (5 min)
   - Update `FIREWALL_URL` in `index.html` to your gateway URL
   - Or keep demo mode for public demo

**Total Time:** 10 minutes
**Result:** Live website!

---

## 🔧 What About the Gateway?

### Two Options:

**Option A: Demo Mode (Easiest)**
- Landing page uses demo mode (no API key needed)
- Gateway can run locally for now
- Public can try demo without your API key
- **Good for:** Public demos, marketing

**Option B: Host Gateway Too**
- Deploy gateway to: Railway, Render, Fly.io, or AWS
- Update `FIREWALL_URL` in landing page
- Users can actually use it
- **Good for:** Real customers using the product

- Gateway can run locally
- Public can try demo safely
- No API key exposure
